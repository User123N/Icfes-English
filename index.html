CENTRO DE CONTROL

Panel docente.

Administra el banco, importa materiales, genera preguntas para revisar y personaliza la proyección. En esta versión los cambios aún se guardan en este navegador; la sincronización con Supabase está pendiente.

Modo docente: este proyecto está adaptado para preparar y proyectar clases. La autenticación real de administrador y la sincronización remota deben configurarse antes de publicar; no uses esta demo sin protección en un sitio público.

Banco de preguntas

Crea, edita o elimina preguntas de práctica.

Usa el mismo título en todas las preguntas que compartan el mismo texto.
Repite el mismo título y texto en las preguntas relacionadas para que la plataforma las agrupe. El texto queda disponible al navegar entre ellas.

Sube tus materiales

Puedes seleccionar PDF, imágenes, documentos de texto, CSV o JSON. En esta versión se almacenan en el navegador; los PDF se registran como materiales, pero no se convierten automáticamente en preguntas.
